# Ejercicio 23 - datos en memoria

Solución sin dependencias externas para practicar **datos en memoria** en el contexto de soldadura.

## Ejecutar

```bash
cd basico/ejercicio-23/resoluciones/cleidy-perez
npm install
npm start
```

## Verificar

```bash
npm run check
```

La entrega incluye `src/app.js` y, cuando el tema lo requiere, módulos de servicio, controlador o middleware. Los datos son locales y no se modifica el enunciado.
